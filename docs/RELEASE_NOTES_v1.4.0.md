# LiveLink v1.4.0 Release Notes

发布日期：2026-05-28

这是给主播朋友测试的新内测版，重点是提升直播间观感和互动留存。

## 新增

- 直播养宠系统：观众可用哈松币领养宠物、投喂升级，并通过观看时长获得经验。
- 像素风宠物资产：3 种宠物，每种 3 阶进化，OBS 底部可常驻展示观众首选宠物。
- 曼波播报风格：TTS 新增轻快抽象的播报预设，不克隆具体人物声线。
- AI 智能回复：新增 DeepSeek API 接入，默认关闭；主播必须填写自己的 API Key 才会调用。
- 观众端主题：新增樱花甜心、糖果泡泡、霓虹夜场、经典简约 4 套 OBS overlay 主题。

## 优化

- 养宠、AI 回复、主题选择都放入主播控制台，配置后实时同步到 OBS overlay。
- AI 回复未填写 Key 时不会触发网络请求，也不会产生 API 费用。
- 像素宠物使用 pixelated 渲染，避免在直播画面里被浏览器平滑成糊图。

## 测试建议

- OBS 浏览器源打开后，在首页切换观众端主题，确认欢迎条、礼物卡、宠物栏视觉同步变化。
- 在宠物页把投喂经验调高，用弹幕测试 `领养宠物 1`、`投喂 1`、`我的宠物`。
- 在 TTS 设置里选择“曼波播报”，点击测试声音。
- 在 AI 回复页不填 Key 时确认状态显示“不会调用 API”；填入主播自己的 DeepSeek Key 后再点“保存并测试”。
