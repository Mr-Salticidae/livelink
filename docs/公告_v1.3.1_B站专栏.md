## 本次更新重点（v1.3.1）

这一版没有加新玩法，是一次把"主播和观众实际用起来的体验"打磨到位的优化，主要解决直播实战中暴露的几个问题：

### 1. 主播弹幕悬浮窗：改成完全透明，不再挡视野

单屏主播玩游戏时会开一个悬浮小窗瞟弹幕。老版本有一层深色半透明底，全屏游戏时挺挡视野。

- 现在窗口**完全透明**，只保留每条弹幕本身的颜色
- 文字加了多层黑色描边，不管游戏画面是雪地白图还是暗场，弹幕都看得清
- 新弹幕进场只做轻微淡入，去掉了原来那块琥珀色高亮底
- 标题栏平时半隐，鼠标移上去才显形，不占视觉
- 粉丝牌等级徽章改成**蓝底白字**（老版本蓝底深字偏暗看不清）

### 2. 给观众看的弹幕信息板：显示 / 延迟 / 截断 全部修好

直播画面上那块滚动给观众看的弹幕板，老版本有三个硬伤，这次全部解决：

- **开了不显示**：修复了配置同步的时序问题，现在开关一开 OBS 里立刻出现
- **延迟严重**：实测优化后"弹幕发出 → 画面渲染"稳定在 **1-2 毫秒**，和实时几乎无差
- **被屏幕边缘切掉**：重写了定位算法，弹幕板拖到屏幕任意位置、任意分辨率下都保证整块完整显示，不会再被边缘截断

### 3. OBS 浏览器源自动更新，不用再手动清缓存

以后每次 LiveLink 升级，你只要重启一下软件，OBS 里的特效层会**自动重新加载新版本**，不用再去 OBS 里手动刷新缓存或改 URL。

> 升级方式：拿到新的 `LiveLink-Setup-1.3.1.exe`，双击安装（覆盖旧版即可），重启软件。OBS 那边什么都不用动。

## 完整功能清单

第一次发布，这里把现有功能完整列一遍。

### 基础自动化

- **进房欢迎**：有人进直播间自动语音播报欢迎，话术可改
- **礼物感谢**：收到礼物自动语音感谢，话术可改
- **关键词回复**：弹幕出现指定关键词（如"你好""哈喽"）自动语音回应
- **TTS 语音播报**：8 种音色可选（4 女声 + 4 男声，含东北话 / 陕西话方言），语速音量可调
- **分事件音色**：欢迎、礼物、SuperChat 等可以各用不同声音，主播不看屏幕也能靠声音分辨发生了什么
- **实时日志**：弹幕 / 礼物 / 进房分类滚动，随时回看直播间动态

### 主播工具

- **弹幕悬浮窗**：游戏全屏时也能瞟弹幕，可钉住进入"鼠标完全穿透"模式（游戏正常操作不误触），标题栏实时显示在线观看人数
- **直播屏弹幕信息板**：弹幕在直播画面上滚动给观众看，位置 / 条数 / 字号可调，礼物事件可选是否进板

### 互动玩法

- **弹幕抽奖**：设奖品 / 关键词 / 中奖人数 / 倒计时，可选粉丝牌门槛，公平随机抽取，结果卡 + 飘彩庆祝
- **互动投票**：2-6 选项实时柱状图，观众发选项号投票，结果赢家高亮
- **竞猜**（主播说了算）：2-8 个选项，观众用哈松币押注，押注期结束后**由主播手动选赢家**，押中的按金额比例瓜分总池。适合"猜今天从哪出大红""猜谁收益最高"这种只有主播能判断的事
- **赛马**（算法出结果）：2-8 匹马，观众押注马号，自动赛跑动画出 🥇🥈🥉，押中冠军的按金额比例分池。纯运气娱乐 / 暖场神器
- **SuperChat 横幅**：收到醒目留言自动按价位分 4 档弹横幅（≥1000 元红金大字 + 屏幕中央粒子特效）并语音念出
- **盲盒查询**：观众发"查盲盒"看自己累计花费 / 中奖 / 净盈亏 + 最近记录

### 哈松币经济

互动玩法共用的一套游戏货币系统，按直播间隔离持久化：

- **送礼自动兑换**：观众送付费礼物按价格自动入账（默认 1 元 = 1000 哈松币，比例可改）
- **新观众开户金**：首次参与自动赠送 1000 哈松币（数值可改）
- **押注赢取**：竞猜 / 赛马猜对按金额比例分池
- **查余额**：观众弹幕发"查余额"，屏幕中央弹出账本卡（余额 / 送礼入金 / 累计押注 / 游戏盈亏）
- 货币名称、初始余额、兑换比例都可在设置里改，全 app 统一生效

### 视觉特效

- **礼物特效按价位分 3 档**：普通飞入 / 金色光晕 / 屏幕中央大字 + 粒子放射，礼物图是从 B 站官方接口拉的真实礼物图，自动本地缓存
- 抽奖 / 投票 / 竞猜 / 赛马开场有大字招牌，出结果有飘彩庆祝

## 怎么用

1. 双击 `LiveLink-Setup-1.3.1.exe`，跟着中文向导一路下一步装完
2. 打开软件，首页填直播间号（直接粘直播间链接也行），点"开始"
3. 复制首页的 OBS 浏览器源 URL，在 OBS 加一个"浏览器"源，粘进去，宽 1920 高 1080
4. 完成。直播间一有动静，OBS 上就会飘特效

> 第一次启动若 Windows 弹蓝色"已保护你的电脑"：点"更多信息" → "仍要运行"。这是没买代码签名证书的小软件的常规提醒，本工具无任何上传行为。
> 详细图文教程见随附的《主播使用说明》。

## 关于隐私和安全（重要）

- **完全本地运行，零上传**：所有配置、规则、观众钱包数据都只存在你这台电脑上
- **B 站登录信息加密保护**：SESSDATA 在保存前会被 Windows 系统级加密（与你的 Windows 账号绑定），配置文件复制到别的电脑也解不开，别人拿到也用不了你的账号
- **完全免费，不需要任何 API key / 账号密码 / 付费服务**
