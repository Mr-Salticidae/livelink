## 本次更新（v1.3.2）

### 1. 装修预览模式 —— 提前看到「满载弹幕」长啥样

直播开播前装修画面时最头疼的：弹幕板平时是空的，不知道直播时塞满了会占多大地方，结果开播一看挡了摄像头一角 / 压住了赞助位。

这次加了一个开关：

- Home 弹幕板设置里打开「**装修预览模式**」
- OBS 里的弹幕板**立刻按你当前设的宽度 / 字号 / 最大条数装满假弹幕**（含礼物、大航海徽章、粉丝牌等真实直播会有的元素）
- 板子右上角飘个金色标识「装修预览·假弹幕」明确提示这是预览
- 你可以一边调宽度 / 字号 / 最大条数，一边在 OBS 里直观看到满载时的真实体积，方便对齐摄像头 / 赞助位 / 其它装饰
- 调好关掉开关恢复真实状态；**重启自动关**，不会忘了关上播带出去

### 2. Home 预览框升级成 WYSIWYG，OBS 实时同步

调弹幕板位置 / 尺寸现在完全在 Home 里搞定，OBS 跟着实时变：

- 预览框按真实 **1920×1080 比例**画板子缩略图
- **拖蓝框**移动位置
- **拖蓝框右下角**缩放真实大小（width / 最大高度）
- 5 个一键贴边按钮：⌜ 左上 / ⌝ 右上 / ● 居中 / ⌞ 左下 / ⌟ 右下，按板子真实尺寸算精确目标位置
- OBS 画面**实时同步**，你在 Home 拖，OBS 那边跟着动，所见即所得
- 实时显示当前坐标 + 尺寸：`x:88% · y:80% · 360×30%`

> 测过 OBS 自带的「交互」拖拽，OBS 的鼠标坐标映射不稳，拖到边角常常不到位。这次干脆全部用 Home 预览框做，效果更精准。

### 3. 赛马报名期：按金额占比的金色热度条

赛马的报名期之前只能看到每匹马的押注人数和金额。这次每匹马下方加了一条**按金额占总池比例的金色进度条**（和竞猜卡同款风格），观众一眼能看出哪匹是热门 / 哪匹是冷门，押注前心里有数。

### 4. 赛马押注 token 解析增强

之前观众发押注必须严格按马号（比如就发 `1`）才算数，发 `1号` `一号` `马号1` `红马` 都会被无视。

这次解析升级，全部能识别：

- `1` ✓
- `1号` `1马` ✓
- `一号` `一` ✓（中文数字 1-10 都行）
- `马号1` `第1` ✓
- `红马`（直接发马名）✓

观众发押注更自然，转化率高一截。

### 5. 内部清理

- 删掉了 OBS 内拖拽（功能不稳）和上版测试遗留的诊断代码（视口尺寸读数、4 角色块、延迟读数），界面更干净
- 配套 7 个文件的代码重构，逻辑清晰了一截

## 怎么开始用

1. GitHub Release 页面下载 `LiveLink-Setup-1.3.2.exe`
2. 双击安装（Windows 弹蓝框点「更多信息 → 仍要运行」是没买代码签名证书的小软件常规提醒，本工具零上传）
3. 打开软件，首页填直播间号（粘直播间链接也行），点「开始」
4. 复制首页那个 OBS 浏览器源 URL，OBS 里加「浏览器」源，粘进去，宽 1920 高 1080
5. 完成。直播间一有动静，OBS 上就会飘特效

老版本用户：直接覆盖安装即可，配置 / 哈松币余额 / 规则全部保留，OBS 那边什么都不用动（升级后 OBS 浏览器源会自动重载新版本）。
