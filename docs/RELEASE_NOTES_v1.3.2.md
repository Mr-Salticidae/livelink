## 🆕 v1.0 之后所有更新

### 💰 哈松币虚拟货币经济（1.1-1.3）

直播间内置的虚拟货币系统，让弹幕互动游戏从"猜对就完事"升级到"押注、拿赔率、看大盘"的真实博弈感。

- **首次开户**自动送初始余额（可配置，默认 1000）
- **礼物自动兑换**为哈松币（rmb/枚比例可配，按礼物价值转换）
- **观众发"查余额"**弹出余额卡（含累计押注 / 累计赢 / 累计充值）
- 余额跨直播间隔离，按 room 持久化

### 🎲 弹幕竞猜（1.1）

- 主播在 Home 出题 + N 个选项；观众发选项号押注
- 实时按金额占比的进度条 + 倒计时
- 主播手动结算赢家，按金额比例分总池
- 押注变更（同一观众改选项）自动退还前面再押新的

### 🐎 赛马接入哈松币押注（1.3）

- 报名期发"马号"押注，按比例分配冠军总池
- 报名卡每匹马下方实时金色占比条，热度一目了然
- 押注 token 支持自然写法：`1` / `1号` / `一号` / `马号1` / `红马` 全部能识别

### 🪟 弹幕板大改（1.3.1-1.3.2）

#### 主播自己看的悬浮窗 — 全透明 ✨
- 窗口背景**完全透明**（之前的深色板挡视野）
- 每条弹幕保留颜色，靠多层黑色描边阴影保证在亮场景（雪地、白图）也能读
- 进场动画去掉琥珀色高亮底块，纯淡入
- 标题栏默认半隐，鼠标移上去才显形；钉住后常驻提醒"鼠标穿透中"
- 粉丝牌徽章蓝底白字（之前蓝底黑字偏暗）

#### 观众看的 OBS 弹幕板 — 全面可调 + WYSIWYG ✨
- **宽度** / **最大高度** / **字号** / **最大条数** 全部 Home 可调
- Home 预览框**真实 1920×1080 比例**，所见即所得：拖蓝框移动、拖右下角缩放、点 5 个一键贴边按钮（⌜⌝●⌞⌟）
- OBS 画布**实时同步**，调的时候 OBS 那边跟着动
- **装修预览模式**：一键把板子塞满假弹幕（含礼物、大航海徽章、粉丝牌），显示满载体积，方便对齐直播间装修
- 修复 OBS 浏览器源缓存：HTML 永不缓存 + JS hash 文件名，更新后只需关掉源属性再确定即可，不用每次手动改 URL `?v=`
- 修复延迟：去掉 backdrop-filter blur（CEF 浏览器源里每帧重采样开销巨大，会拖慢 socket 事件堆积）

### 🛠️ 早期 hotfix（1.0.1-1.0.2）

- 抽奖/投票/赛马改用 `uid|uname` 复合 dedupe key（避免同名观众互相挤掉）
- 主窗关闭时主动 dispose 弹幕悬浮窗，避免进程驻留
